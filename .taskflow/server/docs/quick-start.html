Quick Start

Prerequisites

  • uv — install with brew install uv or curl -LsSf https://astral.sh/uv/install.sh | sh
  • VS Code 1.99+ with GitHub Copilot (agent mode enabled)

1. Clone into your project

For a new project:

git clone https://github.com/pedrogrande/open-taskflow.git my-project
cd my-project

For an existing project, copy these directories into your workspace root:

.github/
.taskflow/
.vscode/mcp.json
.vscode/settings.json
.vscode/hooks.json   # merge with your existing hooks

2. Open in VS Code

VS Code detects .vscode/mcp.json on startup and launches the TaskFlow MCP server automatically via uv. You'll see taskflow listed under Configure Tools (the gear icon in the Copilot chat input bar).

3. Add .taskflow/ to .gitignore

.taskflow/taskflow.db
.taskflow/audit.log
.taskflow/server/__pycache__/

4. Create a project brief

Open .taskflow/project-brief-form.html in any browser, or use this dashboard's New Brief page. Complete all sections and submit.

5. Start the pipeline

In VS Code Copilot chat, use the slash command:

/start-project

Then configure the team:

/setup-team

And run the pipeline:

/run-pipeline

Or use the dashboard

You can also manage everything from this dashboard:

📝 New Brief

Create a project brief using the form, then submit it directly to TaskFlow.

🚀 Run Pipeline

Click "Run Pipeline" on any project to launch the Orchestrator agent in VS Code.

✓ Approve / ✗ Reject

Review and approve or reject tasks directly from the dashboard.

💬 Answer Questions

When agents need human input, questions appear here for you to answer.
